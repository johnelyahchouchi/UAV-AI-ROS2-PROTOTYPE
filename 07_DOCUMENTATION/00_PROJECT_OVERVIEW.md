# 1. Project Overview

## 1.1 Background

Modern UAVs can capture large amounts of visual information during surveillance, inspection and reconnaissance missions. While a human operator can observe the live video feed, continuously monitoring several drones simultaneously quickly becomes difficult, especially in dynamic environments where multiple objects are moving at the same time.

The objective of this project is to transform raw video into structured information that can be processed, shared and visualized inside a robotic system. Instead of acting as a simple camera, the UAV becomes an intelligent sensing platform capable of automatically detecting, tracking and analysing objects of interest.

The system combines computer vision, artificial intelligence, networking and robotics software to provide real-time situational awareness to the operator.
