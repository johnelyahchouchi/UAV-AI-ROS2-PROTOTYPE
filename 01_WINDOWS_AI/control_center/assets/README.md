# Control Center branding asset

`additess_logo_dark.png` is the high-resolution dark-header logo displayed in the
upper-left corner of the Control Center. The original supplied `additess_logo.png`
remains available as a reference.

To change or resize the logo, edit `../branding.json` and set `logo_path`,
`logo_max_width`, or `logo_max_height`. The title, subtitle, author, and internship
period are also editable there.
